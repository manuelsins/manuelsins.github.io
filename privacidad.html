Política de privacidad

Finanzas LatAm Pipeline · Última actualización: 21 de octubre de 2026

Qué es esta aplicación

Finanzas LatAm Pipeline es una herramienta de uso interno del canal de YouTube "Finanzas LatAm". Su único propósito es subir videos producidos por el propio canal a su cuenta de YouTube. No está disponible para otros usuarios.

Datos a los que accede

Con la autorización del dueño del canal, la aplicación usa la API de YouTube para subir videos, miniaturas y subtítulos a ese mismo canal. No lee, recopila ni almacena datos personales de espectadores ni de otros usuarios.

Uso y almacenamiento

Las credenciales de acceso se guardan de forma cifrada solo para ejecutar las subidas. No se venden, no se comparten con terceros y no se usan para publicidad. El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
